## 实现方案

只需修改前端 2 个文件：

### 1. `frontend/src/api/maintenance.js` — 新增导出 API

```js
// 导出维修记录 Excel（返回 blob 二进制流）
export const exportExcel = (params) => {
  const token = localStorage.getItem('token')
  return axios.get('/api/maintenance/export', {
    params,
    responseType: 'blob',
    headers: { Authorization: `Bearer ${token}` }
  })
}
```

> 使用原生 axios 而非封装的 `request` 实例，因为 `request` 的响应拦截器会解析 JSON，blob 响应需要原始数据。

### 2. `frontend/src/views/maintenance/MaintenanceListView.vue` — 添加导出按钮

**模板**：在筛选栏"新建维修"按钮前添加：

```html
<el-button type="warning" @click="handleExport" :loading="exportLoading">
  <i class="el-icon-download"></i> 导出 Excel
</el-button>
```

**脚本**：

```js
import { exportExcel } from "../../api/maintenance"

// data 新增
exportLoading: false

// methods 新增
async handleExport() {
  this.exportLoading = true
  try {
    const res = await exportExcel({
      status: this.query.status,
      category: this.query.category,
      keyword: this.query.keyword
    })
    const blob = new Blob([res.data], {
      type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
    })
    const url = window.URL.createObjectURL(blob)
    const link = document.createElement('a')
    link.href = url
    link.download = '报修工单.xlsx'
    document.body.appendChild(link)
    link.click()
    document.body.removeChild(link)
    window.URL.revokeObjectURL(url)
    this.$message.success('导出成功')
  } catch (err) {
    this.$message.error('导出失败')
  } finally {
    this.exportLoading = false
  }
}
```

## 注意事项

**后端当前导出接口使用分页参数**（`page` + `pageSize`），默认只导出第 1 页的 10 条数据。有两种处理方式：

| 方案 | 说明 | 推荐 |
|------|------|------|
| A. 前端传大 pageSize | 前端调用时传 `pageSize: 9999` 导出所有数据 | ✅ 推荐（零后端改动） |
| B. 后端改导出逻辑 | 后端 export 接口忽略分页参数，查询全量数据 | 更规范但需改后端 |

**方案 A 前端调用示例**：
```js
const res = await exportExcel({
  status: this.query.status,
  category: this.query.category,
  keyword: this.query.keyword,
  pageSize: 9999  // 导出全部
})
```
