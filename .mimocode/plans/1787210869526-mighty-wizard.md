# Excel 导出功能修复计划

## 问题分析

1. **前端 API 调用错误**：`responseType: 'blob'` 被放在请求体中而非 Axios 配置
2. **前端未传递筛选参数**：`handleExport` 只传了分页参数，未传筛选条件
3. **后端缺少导出接口**：`/maintenance/export` 路由未实现

## 修改方案

### 1. 修复前端 API (`frontend/src/api/maintenance.js:38-41`)

```javascript
// 修改前
export const exportExcel = (data) => request.post('/maintenance/export', {
  data,
  responseType: 'blob'
})

// 修改后
export const exportExcel = (data) => request.post('/maintenance/export', data, {
  responseType: 'blob'
})
```

### 2. 修复前端调用 (`frontend/src/views/maintenance/MaintenanceListView.vue:163-187`)

```javascript
// 修改前
const res = await this.$API.maintenanceApi.exportExcel({
  page: this.query.page,
  pageSize: this.query.pageSize,
});

// 修改后 - 传递所有筛选参数
const res = await this.$API.maintenanceApi.exportExcel(this.query);
```

### 3. 实现后端导出接口 (`backend/routes/maintenance.js`)

添加 `POST /maintenance/export` 路由：
- 安装 `exceljs` 依赖
- 复用 `/list` 的筛选逻辑
- 使用 ExcelJS 生成 xlsx 文件
- 返回 Buffer 给前端

### 4. 修复后端导出图片路径问题 (`RepairOrderServiceImpl.java`)

**问题**：导出 Excel 时图片列显示"✗"，原因是使用相对路径读取图片文件失败

**修复方案**：使用绝对路径读取图片

```java
// 修改前
File imageFile = new File(imagePath);

// 修改后 - 获取项目根目录的绝对路径
String basePath = System.getProperty("user.dir") + File.separator;
File imageFile = new File(basePath + imagePath);
```

## 验证方式

1. 启动前后端服务
2. 访问维修记录列表页面
3. 测试无筛选导出 → 应下载当前页数据的 Excel
4. 测试有筛选导出 → 应下载筛选后当前页数据的 Excel
5. 验证下载的 xlsx 文件能正常打开
6. 验证导出的 Excel 中图片能正常显示
